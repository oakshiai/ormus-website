# Keyboard Shortcuts

## Essentials

| Action                                    | Shortcut             |
|-------------------------------------------|----------------------|
| Send                                      | `Enter`              |
| Focus prompt                              | `Tab / Space`        |
| Focus scrollback                          | `Esc / Tab`          |
| Cancel turn                               | `Ctrl + c`             |
| Cycle mode (Normal / Plan / Auto-approve) | `Shift + Tab`          |
| Quit                                      | `Ctrl + q / Ctrl + d`    |
| Command palette                           | `Ctrl + p / ?`         |
| Keyboard shortcuts                        | `Ctrl + . / Ctrl + x`    |
| Open the settings modal                   | `F2 / Ctrl + , / ,`    |

## Input

| Action                                  | Shortcut     |
|-----------------------------------------|--------------|
| Interject while running                 | `Ctrl + Enter` |
| Search prompt history                   | `Ctrl + r`     |
| Toggle multiline                        | `Ctrl + m`     |
| Shell mode (type ! on empty prompt)     | `!`          |

## Conversation Navigation

| Action                    | Shortcut       |
|---------------------------|----------------|
| Select next entry         | `↓`            |
| Select previous entry     | `↑`            |
| Next turn                 | `Shift + →`      |
| Previous turn             | `Shift + ←`      |
| Scroll up one line        | `Ctrl + k`       |
| Scroll down one line      | `Ctrl + j`       |
| Scroll up half page       | `Ctrl + u`       |
| Scroll down half page     | `Ctrl + d`       |
| Scroll up one page        | `Page Up`      |
| Scroll down one page      | `Page Down`    |
